# OnTheMarkNetwork GitHub Organization

This repository contains organization-level GitHub configuration and community health files for OnTheMarkNetwork.

## Purpose

The `.github` repository provides shared GitHub defaults and organization-wide contributor/community guidance. It is not the project headquarters and should not become a general documentation repository.

## Related repositories

- `project-headquarters` — planning, roadmap, standards, architecture, governance, and operations.

## Visibility

This repository is public. Content placed here must be appropriate for public visibility.

## Operating principle

Keep organization-level GitHub infrastructure small, clear, and useful. Add shared configuration when a demonstrated organization-wide need exists.

# OnTheMarkNetwork

**Building the foundation for what comes next.**

OnTheMarkNetwork (OTMN) is an independent network and umbrella organization focused on connecting technology, creative work, communities, consulting, content, and collaboration.

OTMN brings projects, people, ideas, and practical systems together under one network — with an emphasis on building useful things, documenting how they work, and creating a foundation that can grow over time.

## What We're Building

OTMN is developing a network of projects and communities across six connected areas:

- **Technology** — websites, software, open-source work, AI, and digital infrastructure
- **Creative** — digital media, design, branding, and visual communication
- **Communities** — communities built around shared interests, knowledge, and participation
- **Consulting** — digital transformation, strategy, systems, and practical problem-solving
- **Content** — articles, guides, resources, learning materials, and documentation
- **Collaboration** — projects, partnerships, networking, and opportunities to build together

## Our Approach

We believe in building the foundation before the growth requires it.

That means we value:

- Clear vision before unnecessary complexity
- Documentation before institutional memory is lost
- Reusable systems instead of repeated one-off work
- Open collaboration where it makes sense
- Practical experimentation and continuous improvement
- Transparency about what we are building and why
- Small, deliberate steps that create durable foundations

And perhaps most importantly:

> **Sometimes progress isn't another thing you ship. Sometimes progress is knowing what not to build yet.**

## GitHub

This organization uses GitHub as part of its project headquarters, development environment, documentation system, and collaboration infrastructure.

Repositories may serve different purposes — from public projects and community resources to internal planning and research. Each repository should have a clear role, documented lifecycle, and appropriate level of visibility.

Start with the [Project Headquarters](https://github.com/OnTheMarkNetwork/project-headquarters) to understand the organizational structure, roadmap, architecture, standards, and direction behind OTMN.
